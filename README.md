# FlowTrack

FlowTrack is a simple internal task management dashboard built with React. It allows employees to view and complete their assigned daily tasks while giving managers an overview of team progress and the ability to flag tasks that may be at risk.

This project was developed as part of a Frontend Developer / UI-UX Design assessment.

---

## Features

### Employee Dashboard

- View assigned daily tasks
- Mark tasks as completed
- View weekly progress
- Dashboard summary cards
- Priority badges
- Status badges
- Responsive layout

### Manager Dashboard

- View all employee tasks
- Monitor completed and pending tasks
- Flag tasks that are at risk
- Dashboard statistics
- Clean and easy-to-read layout

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
